# 地図で覚える都道府県

実際の県境の地図で、都道府県の位置と隣接関係を覚えるクイズです。地方ごとに、確認問題、位置問題、間違えた県の復習、白地図テストの順に進みます。

全地方に合格すると、地方のヒントなしで全国の地図から答える「全国ランダム10問」「全国47問テスト」、間違いが多い県としばらく出ていない県から出す「今日の復習」が使えます。

公開ページ：https://coff55ee.github.io/mapp/

## 記録について

合格した地方や、よく間違える県の記録は、開いているブラウザの中（localStorage）にだけ保存されます。サーバーには送られません。iPhoneとPCなど別の端末で使うときは、ページ下部の「記録の書き出し・読み込み」で移してください。

## 地図データの出典

「地球地図日本」（国土地理院）を加工して作成しています。

- 使用データ：地球地図日本 第2.2版ベクタ（2016年公開、境界は2015年1月1日時点）の行政界（polbnda_jpn）
- 加工の内容：市区町村界を都道府県単位に統合、線の簡略化、面積3km²未満の小島と小笠原諸島などの省略、先島諸島を枠内へ移動
- 原データの入手元：npmパッケージ [jpn-atlas](https://github.com/biskwikman/jpn-atlas)（BSD-3-Clause）に同梱された原データ
- 利用条件：[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)
- [地球地図日本（国土地理院）](https://www.gsi.go.jp/kankyochiri/gm_jpn.html)

隣接関係は、このデータで県境の線を共有しているかどうかから求めています。岡山県と香川県は、瀬戸内海の井島で陸の県境を接しています。
